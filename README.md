## 🏛️ Executive Summary & Atelier Profile

**SUN LUMINOUS** is an international bespoke architectural decorative lighting, monumental installation, and fine sculptural glass atelier. Positioned alongside global icons such as *Lasvit*, *Preciosa*, *Bocci*, and *WonderGlass*, SUN LUMINOUS pairs centuries-old **1,450°C (2,642°F) mouth-blown crystal furnace craftsmanship** with state-of-the-art **precision structural engineering, parametric CAD modeling, and DALI-2/Casambi smart illumination protocols**.

With India's largest bespoke blowing ecosystem, an in-house heavy metal foundry, and an elite team of 100+ master artisans and structural engineers, SUN LUMINOUS delivers custom turn-key masterworks for luxury five-star hotels, palace properties, landmark corporate headquarters, and ultra-prime private estates across London, Dubai, Delhi, Mumbai, Singapore, and Kathmandu.

## 🔬 300+ Custom Glass Elements (SL Series)

The atelier crafts over 300 proprietary mouth-blown glass element geometries, including:
* **SL 126 (Gitter)**: Textured micro-ribbed blown glass cylinder with champagne undertone.
* **SL 312 (Bubble Sphere)**: Hand-injected captive air-bubble soda-lime crystal sphere with optical refraction.
* **SL 201 (Crystal Shard)**: Hand-chiseled solid borosilicate crystal point with polished bevel edges.
* **SL 165 (Padmara)**: Lotus-petal organic curved glass leaf with 24k gold leaf inclusions.
* **SL 299 (Ambird)**: Sculptural hand-pulled glass bird silhouette illuminated with micro-LEDs.
* **SL 133 (Stelara)**: Starburst multifaceted crystal prism designed for dramatic light scatter.

## 🚀 Getting Started & Local Development

### Prerequisites
- Node.js 18.x or higher
- npm or bun

### Installation
```bash
# Clone repository
git clone https://github.com/your-username/sun-luminous.git
cd sun-luminous

# Install dependencies
npm install
```

### Environment Configuration
Create a `.env` file based on `.env.example`:
```env
PORT=3000
GEMINI_API_KEY=your_gemini_api_key_here
```

### Run Development Server
```bash
npm run dev
```
The application will launch on `http://localhost:3000`.

### Build for Production
```bash
npm run build
npm start
```
